# Q-Mission

## Project Overview
Q-Mission is a web application designed to provide users with a user-friendly interface for logging in and registering to access services offered by Q-Mission. It features a sleek design using Tailwind CSS for styling, ensuring a responsive and mobile-friendly experience. The app allows users to log in using their email and password, as well as register for an account with an activation code.

## Installation
To set up the Q-Mission web application locally, you can follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/q-mission.git
   ```

2. Navigate into the project directory:
   ```bash
   cd q-mission
   ```

3. Open the `index.html` file in your preferred web browser:
   ```bash
   open index.html  # or use a browser of your choice to open the file
   ```

There are no specific installation steps required beyond opening the HTML file since this project does not have a dedicated back-end or require a server.

## Usage
Once you have the application running in your browser:
- You can log in using your registered email and password.
- If you are new, fill out the registration form by providing your email, password, and activation code.
- Utilize the "Show Password" feature to easily view your entered passwords.

## Features
- **User Authentication**: Login and registration functionalities to help users gain access to services.
- **Responsive Design**: A flexible interface that adjusts to different screen sizes.
- **Show Password Feature**: Users can toggle visibility of their passwords while typing.
- **Multilingual Support**: User interface elements are displayed in Spanish.

## Dependencies
This project utilizes the following CDN resources:
- **Tailwind CSS**: A utility-first CSS framework for rapid UI development.
- **Google Fonts (Inter)**: A modern, clean font for a polished look.
- **Font Awesome**: A library for including icons (e.g., eye icons used for password visibility).

For production-grade applications where you want to include local dependencies, consider using npm or yarn for package management.
